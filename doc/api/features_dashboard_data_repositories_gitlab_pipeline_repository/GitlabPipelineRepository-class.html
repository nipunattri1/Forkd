GitlabPipelineRepository

GitlabPipelineRepository class

Real GitLab REST API v4 backed implementation of PipelineRepository.

Resolves the active account, points the shared Dio at the account's domain (so the auth interceptor attaches the bearer token and handles 401 token refresh), then calls GET /api/v4/pipelines.
