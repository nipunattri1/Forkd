GitlabMergeRequestRepository

GitlabMergeRequestRepository class

Real GitLab REST API v4 backed implementation of MergeRequestRepository.

Resolves the active account, points the shared Dio at the account's domain (so the auth interceptor attaches the bearer token and handles 401 token refresh), then calls GET /api/v4/merge_requests.
