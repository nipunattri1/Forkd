# Contributing

- Keep `fvm flutter analyze` at **0 issues** before opening a PR.
- Regenerate freezed / JSON code with `fvm run build_runner build` after any model change.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `refactor:`, `docs:`, ...).
- No new dependencies or abstractions without discussion.
- `presentation` is intentionally misspelled — keep the convention.
